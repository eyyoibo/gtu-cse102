# CSE 102 - Computer Programming (C)

Gebze Technical University | Department of Computer Engineering

Comprehensive coursework, programming assignments, and problem-solving solutions in standard C (ANSI C / C99).

---

## Course Structure

The coursework is organized by semester offerings, providing a unified and complete archive of all programming problem sets:

### 📁 Spring 2025 (Full Coursework)
- **`HW01_ErrorAndGeometry/`**: Experimental vs theoretical error percentage calculations and 2D circle geometry calculations.
- **`HW02_GridGame/`**: 2D grid-based navigation game using scalar variables and file persistence.
- **`HW03_ATMSimulator/`**: Menu-driven Virtual ATM banking simulation with transaction history.
- **`HW04_RocketSimulation/`**: Physics-based quadratic vertical flight trajectory modeling with terminal rendering.
- **`HW05_BattleshipGame/`**: Complete 10x10 Battleship simulation with ship placement, hit logging, and coordinate verification.
- **`HW06_CodebreakerVault/`**: Mastermind-inspired number-guessing cryptographic game with admin/player modes and scoring.
- **`HW07_Minesweeper/`**: Terminal Minesweeper game with dynamic grid sizes (2x2 to 10x10), mine placement, and undo functionality.
- **`HW08_SlidingWindow/`**: Sliding-window maximum and average calculations over numeric streams with color-coded terminal output.
- **`HW09_QAEncoding/`**: Natural language question-answer one-hot character embedding pipeline with binary serialization.
- **`HW10_QAKnowledgeBase/`**: Vector embedding cosine similarity search and nearest-neighbor question answering engine.
- **`HW11_WizardWar/`**: Recursive turn-based elemental wizard duel simulation with struct spellbooks and recursive scoring.
- **`HW12_Reversi/`**: Two-player Reversi / Othello game against a greedy AI opponent with dynamic board sizing (4x4 to 20x20).
- **`HW13_MiniDatabase/`**: In-memory relational database engine supporting ANSI SQL commands (`INSERT`, `DELETE`, `UPDATE`, `TRUNCATE`) and formatting.
- **`HW14_StudentManagement/`**: Dynamic singly-linked list student management system with GPA computation and credit weighting.

### 📁 Fall 2024 (Programming Assignments)
- **`PA01` - `PA07`**: Core foundational programming challenges in modular C.

### 📁 Spring 2024 (Historical Problem Sets)
- **`HW01_Encryption/`**: Custom substitution cipher encryption and decryption tools.
- **`HW02_DataExploration/`**: 2D coordinate parsing and boundary detection.
- **`HW03_WallGame/`**: 16x16 matrix obstacle navigation.
- **`HW04_ArrayStatistics/`**: Mean, median, and mode statistical analysis algorithms.
- **`HW05_NewsReader/`**: File-persisted news reader and article metadata tracking.
- **`HW07_MancalaGame/`**: Traditional Mancala board game logic and stone distribution.
- **`HW08_GPADatabase/`**: Multi-file database merging and student GPA computation.

## Compilation

All source code complies with standard ANSI C and can be compiled using GCC:
```bash
gcc -ansi -Wall -Wextra -pedantic main.c -o program
./program
```
